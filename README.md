EN
This is the unofficial revised version of the RPG MAKER MV plugin 「イベントの頭上に文字を表示するプラグイン」(Display Text above an Event) by 蔦森くいな (Kuina Tsutamori). A bug where the "info" text was not displayed during loading has been fixed. I reported the issue via blog and X but have not received a reply, so I am releasing this under the MIT License. This repository would be removed once an official fixed version is released by the original author.
